# Cruzain Pyrazolone CADD Data Repository

This repository contains supporting data for the manuscript:

"Molecular Modeling Design of Antitrypanosomal Pyrazolone Derivatives Targeting Chagas Disease: QSAR, Docking, Molecular Dynamics and Free Energy Calculations"

The repository includes QSAR matrix data, docking poses, MD CPPTRAJ analysis, MM/GBSA input/output files, per-residue decomposition data, and high-resolution figures.

## Systems

The following cruzain systems are included:

- CP3
- CP98
- LMM1
- LMM2
- LMM3
- LMM4

## Main analyses

1. 2D-QSAR modeling
2. Molecular docking
3. ADMET predictions
4. Molecular dynamics simulations
5. Protein and ligand RMSD
6. RMSF
7. PCA/FEL
8. MM/GBSA binding free energy estimates
9. Per-residue energy decomposition
10. Apo force-field/water-model comparison

## Software

The main software used includes MOPAC, ChemDes, UseGalaxy, QSARINS, GOLD, FITTED, AutoDock Vina, Gaussian 09, Amber20, CPPTRAJ, MMPBSA.py, OSIRIS, SwissADME, and ADMET-AI.
