# Cruzain Pyrazolone CADD Data Repository

This repository contains supporting data for the manuscript:

"Molecular Modeling Design of Antitrypanosomal Pyrazolone Derivatives Targeting Chagas Disease: QSAR, Docking, Molecular Dynamics and Free Energy Calculations"

The repository includes QSAR matrix data, docking poses, AMBER files, MM/GBSA output files, per-residue decomposition data, and high-resolution figures.

## Systems

The following cruzain systems are included:

- CP3
- CP98
- LMM1
- LMM2
- LMM3
- LMM4

## Main analyses

1. 2D-QSAR modeling
2. Molecular docking
3. MD and Free Energy Analysis
4. Apo force-field/water-model comparison
5. High quality figures

## Software

The main software used includes MOPAC, ChemDes, UseGalaxy, QSARINS, GOLD, FITTED, AutoDock Vina, Gaussian 09, Amber20, CPPTRAJ, MMPBSA.py, OSIRIS, SwissADME, and ADMET-AI.
